# Netflix Tableau Dashboard
## Project Overview
This project presents an interactive Tableau dashboard analyzing Netflix movies and TV shows.

## Objectives
- Analyze the distribution of movies and TV shows on Netflix.
- Explore content by genre, country, and release year.
- Identify trends in Netflix content over time.
- Present the analysis using interactive Tableau visualizations.

## Tools Used
- Tableau
- Excel / CSV Dataset
